# 能力决策与按需工具

新安装和更新后的正式、临时聊天默认先提交一次 `gateway_turn_decision`，再生成答复或调用业务工具。此步骤使用当前选定模型，计入模型调用次数和额度；模型必须支持结构化工具调用。不更换 Provider 或为用户接入外部服务。

决策包括一段简短、中性的动作或心理描写，以及文字/语音、记忆、贴纸、引用、图片和工具组的选择。描写是否显示仍由独立的 `/expression` 设置控制，默认关闭；不展示模型分析过程。每轮台词选择文字或语音一种，语音可合理分段，发送失败沿用现有文字回退和防重复机制。已有投递记录按原状态恢复。

| 能力 | 当前行为 |
| --- | --- |
| 记忆检索 | 先判断上下文是否足够；需求分数达到 0.6 时用短关键词搜索或按已有 ID 读取。每轮最多两次搜索，默认每次 8 条。需要核对原文时仍可检索历史。 |
| 图片 | 正式/临时聊天只在用户明确要求生成或编辑图片时开放，仍受渠道、配置与付费权限约束。 |
| 贴纸 | 选择是否考虑贴纸，再查询最多 8 个候选或复用已知素材标识；发送前核验机器人与会话。 |
| 引用 | 只选择当前聊天中实际存在的平台消息，不生成虚构引用。 |
| 提醒与主动计划 | 按需加载 `plans`；提醒仍须实际创建成功。每日规划关闭时不提供重新规划工具。 |
| 文件 | 按需加载 `files`；原有路径范围、管理员校验及修改/删除确认机制继续生效。 |
| Recent 管理 | 读取工具直接可用，写入工具在 `recent_manage` 组；临时聊天只读。 |
| MCP | 每个已配置服务一个组，只包含既有允许列表内的工具；未配置时没有 MCP 组。后台授权继续单独配置。 |

模型可以在最初决策中选择需要的组，也可以中途调用 `gateway_load_tools`。加载成功后的**下一次模型请求**才提供新工具；同一响应中“加载后立即执行”的调用会被拒绝。工具组每轮重置，不会因历史中出现工具名称就获得执行权限。

若自定义模型无法可靠提交该决策，可设置 `GATEWAY_TURN_DECISION_ENABLED=false` 并重启作为兼容方式。按需工具加载和执行权限校验仍有效；不是给不支持工具调用的模型提供完整兼容。

## 上下文与 Recent

Core 与固定规则放在会话建立/恢复输入的前部；记忆重建摘要、Recent 快照和历史依次组织。SIWC 在正常延续时不重复发送 Recent 快照，需要最新状态时读取 `gateway_recent_read`。通用 API 和 OpenRouter 是无状态请求，每次仍提供当前快照。

Recent 保存待接续话题、待跟进事项和待分享内容；记忆图保存稳定事实与已结束经历。图引用不隐藏 Recent，也不关闭后台整理。时间、Core 遵循提醒及当前消息状态仍逐轮提供。

控制中心的调用流程按规则、重建快照和每轮信息显示来源，展示实际提供的工具定义，并标记诊断内容省略或截断。诊断记录不改变模型输入、工具权限或投递结果。
