# 临时会话

管理员在 Telegram 私聊使用 `/temp on` 开启，`/temp off` 退出。使用当前 Provider 和当前模型，复用普通聊天的提示词和工具执行方式。存在待处理正式回复时须先完成或处理该回复。进程重启会退出临时模式。

临时对话只在内存保留，最多 100 条消息或约 200000 字符；达到上限后退出再开启。不会写入正式聊天、Recent、记忆图、正式调用轨迹、Provider 对话检查点或付费文本调用日志。失败不自动重试，只有确认送达的回复进入内存上下文。服务端和 Telegram 自身的数据保留政策不由此设置控制。

可以读取已有正式历史、Recent 和记忆；文件操作、附件缓存、生成图片和贴纸目录仍会保存，文件写入与删除继续遵守原有授权范围。Core 与 Recent 写入工具不提供给临时对话。按本轮范围，临时会话不接入可选 MCP。

退出只清除内存对话，不撤销已执行的文件或外部操作。当前入口仅支持已配置管理员的 Telegram 私聊，群聊和微信不自动进入临时模式。
